# Synthesised, not hand-written

These templates are generated by `examples/cdk/app.py` and copied here. Regenerate both
this scenario and `examples/cdk/synthesized/` with:

```bash
python scripts/dev.py synth
cp -r examples/cdk/synthesized/baseline examples/scenarios/cdk-multi-stack-growth/baseline
cp -r examples/cdk/synthesized/proposed examples/scenarios/cdk-multi-stack-growth/proposed
```

Do not edit them by hand. `dev.py test-cdk` compares them against a fresh synth.
